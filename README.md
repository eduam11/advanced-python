# advanced-python
My personal notes (Jupyter notebooks) for learning intermediate and advanced Python topics.

## Installation
First, clone this repository using Git:

```bash
git clone https://github.com/eduam11/advanced-python
```
And install the required dependencies:

```bash
pip install -r requirements.txt
```
